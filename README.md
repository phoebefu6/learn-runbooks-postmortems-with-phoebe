# Learn Runbooks & Postmortems with Phoebe

Ten interactive sessions, by Phoebe Fu, on incident docs as a system: keeping a whole library of
runbooks true as systems change, and writing postmortems the team, the executive and the customer
can each act on.

- **Writer track (6 sessions):** count the library, find where pages go stale, drill them, write the
  team postmortem, read a year of postmortems as one, and score the docs kit on the bench.
- **Leader track (4 sessions):** which docs must exist, the review people come to, writing for the
  customer, and actions that close.

The running case, Pellmoor (a same-day online grocer), is constructed. The docs bench runs in the
browser: a real rule engine for runbooks and postmortems, and a library model whose drift rate is a
simulated, labelled parameter. Open `index.html` to start; no build step, no server needed.
